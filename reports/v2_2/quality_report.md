## Honest limitations

- move and cairo toolchains (sui, aptos, scarb, snFuzzer) are not installed, so no local L3-L6 for Move/Cairo except the one sui-toolchain Move run (move:cetus-checked-shlw, L6)
- the report layer declares no licence for 109 of 112 sources, which stay content_license=unknown and not redistributable
- no model has been evaluated: these files describe the instrument, not a result
- most of family N is unlabeled by design: only the records whose sources actually state an attacker standing are graded, because inferring one would be the model's job, not the dataset's.
- family Q grades the application of a published rubric to observed properties; it does not grade whether the rubric is the right one.
