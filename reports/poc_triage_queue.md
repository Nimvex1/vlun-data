## Per-record fields

Each row of `derived_poc_queue/triage_queue.jsonl` carries: stable finding id, repository and pinned vulnerable revision, a PoC *pointer* (dataset path plus upstream URL and the sha256 of the quoted bytes - the PoC code itself is not copied into this queue), the required toolchain, what dependency configuration is available locally, the patch reference, the assertion the PoC makes, the eligibility verdict and the blocker classes.
