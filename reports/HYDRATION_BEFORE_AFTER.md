# Hydration Before/After — VLUN dataset

Generated by the gate owner at final Wave 3. Sources:
`reports/metadata_vs_trainable_audit_before.json` (pre-hydration, preserved) and
`reports/metadata_vs_trainable_audit.json` (post-hydration, parallel audit, verified by
`scripts/verify_audit.py`).

**Classifier correction note:** this table was rebuilt from the corrected AFTER audit.
The old `explicit_metadata_flag()` flagged ANY string whose value was exactly
`METADATA_ONLY`/`POINTER_ONLY`, including rights/licensing/governance fields
(`data_handling_policy`, `distribution`, `license`). Rows with inline code AND prose in
`jsonl_v4/findings.jsonl`, `distribution_v1/records_v4.jsonl`,
`distribution_v1/records_v1.jsonl` and `derived_span_tasks/answer_key.jsonl` were
therefore wrongly binned as `METADATA_ONLY_STUB`. The token check now applies only to
extraction-flag fields; genuine stub markers (`redistribution: METADATA_ONLY` in
`jsonl_v3/sources.jsonl`, `data_handling: METADATA_ONLY` in wave1 governance) still flag.
See `reports/_classifier_fix_notes.md`.

**Method:** per-layer rows/buckets come from `by_layer[layer]`. Percentages are the
audit's published `coverage_pct_avg` per layer (row-weighted by the auditor across the
files in that layer), used verbatim. Before has 189 files, after has 196 — the extra
files are new quarantine/bookkeeping ledgers created by the purge.
